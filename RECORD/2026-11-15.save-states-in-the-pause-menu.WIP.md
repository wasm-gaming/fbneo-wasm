# Save states in the pause menu

2026-11-15 13:44 · owner: "me gustaría que los savestates salgan directamente en el menú de pausa". The same
change goes to blastem-wasm's app (this app on BlastEm's SDK), its own record.

**Status:** proposal — awaiting the owner's approval.

## Today

Pause → *Continuar · Puntos de suspensión · Reiniciar · Volver al lanzador*. "Puntos de suspensión"
writes the unsaved point (slot 9, with the frame taken when the menu opened) and opens another
screen (the boot one, one level down) where Y copies it into one of the four slots. Loading a slot
is only possible from that screen. Two screens and two buttons to save; loading hidden.

## Proposal

The four slots **in the pause panel itself**, as a row of cards between "Continuar" and the rest:

```
  GRIDLEE
  Pausa
  [ Continuar                                   ]
  Puntos de suspensión
  [ 1 ▣ hoy 13:20 ] [ 2 ▣ hoy 13:41 🔒 ] [ 3 ┄ vacío ] [ 4 ┄ vacío ]
  [ Reiniciar                                   ]
  [ Volver al lanzador                          ]
   A elegir · B continuar
```

- **Moving**: up / down between rows (Continuar → the slots → Reiniciar → Volver); left / right
  along the slots. Opening the menu still focuses "Continuar" (UX.md rule 1).
- **An empty slot**: A saves the current moment there at once — its frame is the one taken when the
  menu opened — and the card shows it ("Guardado en el hueco 3").
- **A saved slot**: A opens its sheet — **Cargar** (focused; loads it and goes back to the game),
  **Guardar aquí** (overwrites: asks first, default No — rule 6), **Bloquear / Desbloquear**,
  **Borrar** (asks first). A locked slot offers only Cargar and Desbloquear.
- **Touch** (the pad is hidden in menus): a tap is A; the hints are buttons, as already.
- **Unchanged**: the boot screen when coming back (the unsaved point, the four slots, "desde el
  principio"), and "Volver al lanzador" still leaving the unsaved point. The pause menu's
  "Puntos de suspensión" entry goes — its job is now the row.
- Hints on a slot: "A guardar aquí" (empty) / "A opciones" (saved), "B continuar".

## Changes

`src/app/app.js` (pause state gains a focus row/column; render; `onPause` navigation; slot
actions reusing `states.save/load/lock/remove` and the existing sheet / confirm), `src/app/app.css`
(a compact card row inside the panel; wraps 2 × 2 on a narrow phone). No SDK change.

## Verify

`make test`; end to end on Gridlee (phone emulation, touch pad): pause → save into slot 1 →
