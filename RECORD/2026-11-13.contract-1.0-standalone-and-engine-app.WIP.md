## Where it is (verified at `6aede01`, v0.1.2)
- Legacy contract: `{ manifest, load(config) }` → `EngineInstance`; engine-specs `^0.2.3` as a
  devDependency + optional peer; `manifest.json` emitted; demo built from engine-specs' shared shell.
- Upstream FBNeo cloned at `master` HEAD — **not pinned**; CI image `emscripten/emsdk:latest` — not
  pinned. Patches use `sed`/`str.replace` without checking they applied.
- `fbneo.js` is a classic script defining the global `createFbneoModule` (not an ES module).
- The main loop is FBNeo's own blocking `RunMessageLoop()` yielding through ASYNCIFY
  (`emscripten_sleep`): there is **no emscripten main loop**, so the SDK's
  `pause()` → `Module.pauseMainLoop()` does nothing; `reset()` throws; `destroy()` only "pauses".
- **Nothing persists**: NVRAM/EEPROM and states go to `SDL_GetPrefPath` (`/libsdl/fbneo/config/games/`),
  hiscores to `…/support/hiscores/`, all in MEMFS, lost on reload.
- No `AGENTS.md` / `RECORD/` (an old `SESSIONS/` file); no tests beyond `tsc`.
- Kept as they are: `romset.ts` (driver from CRC-32s), `neo.ts` (`.neo` → ROM set), `data/romsets/`.

## Changes

1. **Pinned build** (`scripts/build-fbneo.sh`): FBNeo at a fixed commit (the current HEAD,
   `2c6dac37`, unless the owner prefers the commit 0.1.2 was built from); `emscripten/emsdk:6.0.2`
   in the Docker wrapper and CI; every source patch asserts it matched. `-sEXPORT_ES6=1`, so the
   SDK `import()`s the glue like every other engine.
2. **Native bridge** (appended C++ in the build, `EMSCRIPTEN_KEEPALIVE` + `EXPORTED_FUNCTIONS`):
   - `web_set_paused(int)` — the ASYNCIFY loop keeps yielding but runs no frame and stops the
     sound while paused (the loop is FBNeo's, so pausing has to happen inside it);
   - `web_reset()` — `BurnDrvReset()` → `restart()` becomes a real soft reset;
   - `web_persist()` — NVRAM/EEPROM written now (`BurnAreaScan` via the burner's own save path),
     so the SDK can mirror it; `web_save_state(slot)` / `web_load_state(slot)` — `BurnStateSave/Load`
     to `<save dir>/slot_N.fs`.
   - The save folder (`szAppEEPROMPath`, hiscores) is redirected to one MEMFS dir, `/save`.
3. **SDK on contract 1.0** — `FbneoSDK` / `FbneoPlay` (`static id = 'fbneo'`), modelled on
   blastem's:
   - config: `renderFilter` (live), `jsUrl`, `wasmUrl`; options: `driver`, `romFileName`
     (as today: the driver comes from `driver`, else the file name);
   - assets: `rom` (zip/7z, required), `bios` (zip, optional, e.g. `neogeo.zip`);
   - storage: `namespace`, `persist` → OPFS `fbneo/<namespace>/` via the same `storagePath()`;
     `/save` seeded before boot, mirrored every 10 s, on pause, page hide and destroy; `saves` event;
   - owner-aware `pause(owner)` / `resume(owner)`, `restart()` (soft reset), `destroy()`,
     `states` (save/load/list, slots 0-3 + the suspend point 9, as blastem's), `snapshot()`;
   - self-contained ESM (engine-specs copied beside it, imports localized); engine-specs `^0.4.0`
     as a regular dependency; manifest and `emit-manifest.mjs` removed; `romset`/`neo` exports kept.
4. **App** `src/app/` → `dist/fbneo/app/`: boot screen, then the game; pause menu (Select+Start /
   Escape): Continuar, Reiniciar, Guardar / Cargar estado (slots), Volver al lanzador (asks).
   Same structure and look as the rsdk/blastem apps.
5. **Repo**: `CLAUDE.md -> AGENTS.md`, `RECORD/` (the `SESSIONS/` file moved and classified), no-build
   demo (`src/demo/index.html`, keeps the `.neo` and romset helpers), tests (`storagePath`, the app's
   pure parts, SDK loads with no import map), workflows aligned with blastem's (pinned image,
   `fbneo.tar.gz` with `fbneo/fbneo/`), README rewritten, `sync-version.mjs`, `localize-specs.mjs`.
   Breaking: **0.2.0** via the release workflow (minor while < 1.0); the launcher has to move from
   `load()` to the SDK class (play.germade, not in this session).

## Verification plan
Build the wasm here (Docker; GitHub archive downloads for emscripten ports seeded from git, as
done for rsdkv5). `make test`. Chromium: the SDK loads with no import map; a missing ROM shows the
app's error screen; with a freely distributable ROM set if one boots in FBNeo (none is in the repo;
otherwise the owner's): runs ~60 fps, pause stops frames and sound, reset, state save/load,
NVRAM mirrored to OPFS and restored after reload.

## Risks
- The FBNeo compile is long (all drivers); a pinned HEAD may need patch updates.
- ASYNCIFY + a pause flag inside FBNeo's loop is new ground for this repo.
- No arcade ROMs here: game-level checks depend on a free ROM set booting, or on the owner.
